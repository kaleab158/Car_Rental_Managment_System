# Abyssinia Car Rental System

A Java-based vehicle management and car rental system built using the MVC (Model-View-Controller) architecture.

## 📁 Project Structure

```
Class Structures/
├── Car_Rental_System.java   # Main system class / entry point
├── Customer.java             # Customer model
├── Employee.java             # Employee model
├── Login.java                 # Login/authentication logic
├── Payment.java               # Payment processing
├── Registration.java          # User/customer registration
├── Reservation.java           # Reservation handling
└── Vehicle.java                # Vehicle model
```

## ✨ Features

- Customer registration and login
- Vehicle browsing and reservation
- Payment processing
- Employee management
- MVC-based architecture for clean separation of concerns

## 🛠️ Built With

- **Java** — core application logic
- **MVC Architecture** — for maintainable, organized code

## 🚀 Getting Started

### Prerequisites
- JDK installed (version X or higher)

### Running the project
```bash
javac Car_Rental_System.java
java Car_Rental_System
```
